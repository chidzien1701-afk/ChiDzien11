HƯỚNG DẪN SỬ DỤNG WEBSITE CÁ NHÂN - NGUYỄN ANH KHOA
====================================================

1. Cấu trúc thư mục:
   - index.html        : Trang chủ (Giới thiệu cá nhân Nguyễn Anh Khoa, CLB Thông tin Xung Kích, MacBook Neo vàng chanh)
   - hoat-dong.html    : Trang Hoạt động & Dấu ấn (CLB, Design, Nhảy múa & bộ lọc tương tác)
   - lien-he.html      : Trang Liên hệ & Góc hỏi vui
   - assets/css/style.css : File định dạng giao diện (tông Indigo - Vàng chanh - Pastel)
   - assets/js/main.js    : Xử lý menu di động, bộ lọc hoạt động, FAQ và form liên hệ
   - assets/images/avatar.png : Hình đại diện kỳ lân cầu vồng

2. Cách mở xem trên máy tính:
   - Giải nén file `nguyen-anh-khoa-website.zip` ra một thư mục.
   - Nhấp đúp chuột vào file `index.html` để mở trực tiếp bằng trình duyệt (Chrome, Safari, Edge...).
   - Có thể mở bằng Adobe Dreamweaver hoặc VS Code để chỉnh sửa thêm nội dung tùy ý.
