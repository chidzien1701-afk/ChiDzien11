HƯỚNG DẪN SỬ DỤNG WEBSITE CÁ NHÂN - VÕ TRÍ VIỄN
=================================================

1. Cấu trúc thư mục:
   - index.html      : Trang chủ (Giới thiệu cá nhân, kỹ năng & thông tin nổi bật)
   - du-an.html      : Trang Dự án & Hành trình (Thực tập, tình nguyện, nhiếp ảnh, thiết kế)
   - lien-he.html    : Trang Liên hệ & Câu hỏi thường gặp
   - assets/css/style.css : File định dạng giao diện (màu sắc, bố cục, responsive)
   - assets/js/main.js    : Xử lý menu di động, bộ lọc dự án, FAQ và form liên hệ
   - assets/images/avatar.png : Hình đại diện của bạn

2. Cách chạy thử trên máy tính:
   - Giải nén file .zip này ra một thư mục bất kỳ.
   - Nhấp đúp chuột vào file `index.html` để mở trực tiếp bằng trình duyệt (Chrome, Safari, Edge...).
   - Bạn cũng có thể mở thư mục này bằng Adobe Dreamweaver hoặc VS Code để chỉnh sửa nội dung, gắn link Facebook/Zalo cá nhân theo ý muốn.
